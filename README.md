# HoleShot

Il s'agit d'un projet scolaire réalisé à deux dans le cadre d'une découverte des interactions spécifiques au support mobile. Pour cela, nous proposons dans ce projet l'élaboration d'un minijeu dans lequel l'utilisateur utilise l'accéléromètre intégré dans le téléphone afin de déplacer une boule dans un trou.
L'objecif du jeu est de réaliser le meilleur score possible dans un temps imparti.
